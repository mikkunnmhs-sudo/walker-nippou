# 業務日報

iPhone用の業務日報アプリ（Walker業務日報アシスタントのヘルスケア風リデザイン版。LINE報告文作成・Googleフォーム自動入力・履歴）。

- アプリ: https://mikkunnmhs-sudo.github.io/walker-nippou/
- スプレッドシート連携用のApps Script: `gas/spreadsheet.gs`
- 履歴タブはスプレッドシートから読み込むので、どの端末でも同じ履歴が見られます（`gas/spreadsheet.gs` の doGet）。
- 名前やURLなどの設定は、iPhoneの中だけに保存されます（このページには入っていません）。
